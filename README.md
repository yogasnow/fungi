# Fungi · от клетки к лесной истории

Публичная учебная лаборатория Снежаны: биология, виды грибов, молекулы, код и визуальная история. Научные факты и художественные образы разделены; материалы не являются советом по лечению, сбору или употреблению грибов.

## Начать здесь

1. [Строение гриба](biology/README.md): атом → молекула → клетка → гифа → мицелий → плодовое тело.
2. [Каталог видов](catalog/README.md): пищевые виды и отдельные исследовательские темы без смешения с рекомендациями к употреблению.
3. [Молекулы и доказательства](compounds/README.md): β-глюканы, хитин, эргостерол и вещества, требующие особой осторожности.
4. [TypeScript-словарь видов](code/fungi.ts) и [соединений](code/compounds.ts): учебные данные о строении и веществах; учебный код для изучения структуры данных.
5. [Mushroom Blend + Shilajit](product-study/mushroom-blend-shilajit/README.md): что реально написано на банке и чего по этикетке определить нельзя.

## Разработчику

Начни с [словаря видов](code/fungi.ts), затем открой [словарь соединений](code/compounds.ts). С Node.js 22+ файлы можно запускать отдельно:

```sh
node --experimental-strip-types code/fungi.ts
node --experimental-strip-types code/compounds.ts
```

Код в `code/` можно использовать и развивать по [лицензии MIT](CODE-LICENSE.md). Она **не распространяется** на иллюстрации, тексты и фотографии. Хорошее следующее расширение — отдельная проверяемая карточка вида с полями «источник», «наблюдение» и «что не установлено».

[Star Seeds · Акт III «Мир Fungi»](star-seeds-act-03-fungi/README.md) — отдельная сказка: обложка, пролог, 12 глав с раскадровками и полными репликами. Изображения служат художественными образами, не научными снимками или диагностическими схемами.

[План научной проверки](RESEARCH-PLAN.md) отделяет известное по этикетке от вопросов по биологии, химии и клиническим исследованиям.
