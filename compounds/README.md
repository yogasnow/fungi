# Соединения и уровень доказательств

- **Хитин** — структурный полисахарид клеточных стенок многих грибов.
- **β-глюканы** — семейство полисахаридов, а не единая молекула. Содержание и структура меняются между видами, частями организма и способами экстракции. Сам факт β-глюкана на этикетке не доказывает клинический эффект.
- **Эргостерол** — компонент мембран грибов; под действием УФ может превращаться в витамин D₂. Содержание в конкретном продукте измеряют, не выводят из названия вида.
- **Псилоцибин / псилоцин** — отдельная тема клинических исследований в контролируемых условиях. Предварительные результаты нельзя превращать в совет для самостоятельного лечения.
- **Иботеновая кислота / мусцимол** — вещества красного мухомора с токсикологическими рисками. Это не взаимозаменяемые вещества с псилоцибином, и здесь нет инструкции по приготовлению или применению.
- **Шиладжит** — не гриб и не «грибной фермент»; для оценки продукта нужны происхождение, состав и независимые проверки загрязнений.

**Ферменты:** этикетка изучаемой смеси не называет конкретные ферменты и их активность. Мы не приписываем продукту список ферментов без лабораторного анализа. В будущих карточках отделим ферменты, которые *может производить живой гриб*, от веществ, которые *обнаружены в готовом экстракте*.

Для медицинского раздела потребуется таблица по каждому утверждению: вид/вещество, форма, доза, популяция, контрольная группа, исход, публикация, качество доказательств, риски. До заполнения такой таблицы лечебные заявления остаются гипотезами.
