# От атома к плодовому телу

**Атомы** (C, H, O, N и другие) входят в состав **молекул**. Клеточная стенка многих грибов содержит **хитин** и разные **β-глюканы**; состав зависит от вида, стадии и метода анализа. **Клетки** формируют нитевидные **гифы**. Сплетение гиф называют **мицелием**. У ряда грибов при подходящих условиях образуются **примордии**, затем **плодовые тела**, где формируются споры.

Эта последовательность — учебная модель, а не одинаковая схема для всех грибов. Например, дрожжи могут существовать в одноклеточной форме; не каждый гриб образует привычную шляпку. «Гриб» в пищевом магазине часто означает плодовое тело, тогда как организм включает и скрытую сеть гиф.

Для следующей карточки: нарисовать одну гифу и сеть мицелия, подписать клетки и стенку; отдельно показать плодовое тело и отметить, какие структуры реально видны без микроскопа.
