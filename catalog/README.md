# Каталог для изучения

| Рабочее название | Научное название / группа | Статус в этом проекте |
|---|---|---|
| Вешенка обыкновенная | *Pleurotus ostreatus* | пищевой пример; изучить гифы и плодовое тело |
| Ежовик гребенчатый | *Hericium erinaceus* | пищевой пример; отделять продукт от исследования экстракта |
| Шиитаке | *Lentinula edodes* | пищевой пример |
| Шимеджи | торговое имя для нескольких видов, включая *Hypsizygus tessellatus* | уточнять вид на упаковке |
| Эноки | *Flammulina filiformis* | пищевой пример; уточнять вид на упаковке |
| Лисички | группа *Cantharellus* | дикорастущие: идентификация по карточке небезопасна |
| Чага | *Inonotus obliquus* | отдельная тема о древесном грибе и продуктах из него |
| Красный мухомор | *Amanita muscaria* | исследовательская тема о токсикологии; не пищевой/лечебный совет |
| Псилоцибинсодержащие грибы | несколько разных видов | исследовательская тема о клинических работах и правовом статусе; не инструкция по употреблению |

Не переносить лечебные свойства из вида на любой экстракт или банку: важны идентификация, часть организма, метод получения, доза, стандартизация и качество исследования.
