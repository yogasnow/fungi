# Как участвовать

- Для исправления биологического факта укажи вид, источник, страницу или DOI и точную фразу для правки.
- Для изменения TypeScript открой Pull Request с коротким примером проверки.
- Для истории Star Seeds предложи правку текста отдельно от научного раздела; изображения не заменяй без согласования с автором.

Не добавляй инструкции по употреблению дикорастущих или психоактивных грибов и неподтверждённые лечебные обещания.
